# 初始实验协议与结论边界

## 任务与数据

当前任务是二分类情感分析。Qwen 基础模型将 `Review: ...\nSentiment:` 映射到 ` negative` / ` positive`；仅答案与 EOS 参与训练损失。评价采用两种完整答案序列的条件负对数似然之和，选择损失更低者，不依赖自由生成解析。基础权重冻结，LoRA 使用固定同构秩。`max_length` 包含提示、答案与 EOS，评论从右侧截断。

SST-2 官方 validation 在本协议中作为最终测试池，隐藏标签 test 不使用；IMDB 使用官方 test。训练池中独立抽取 root 与 validation，再分配客户端。跨池按规范化文本哈希去重。每个池、每个客户端的标签平衡。普通客户端分配与异质域比例变动配对，异质客户端从预留的两域池中选择样本。

`pilot.yaml` 为 20 个客户端、每轮抽 10 个、5 个正常异质客户端、每客户端 500 样本、0.4 混合比例、3 个计划种子、10 轮、1 本地 epoch、rank 4 / alpha 8、q_proj/v_proj。学习率 2e-4、有效 batch 16、长度 256、固定 beta 0.2 是明确新增的初始选择，需用验证集检查学习曲线，不声称来自原报告未提供的配置。SST-2 与 IMDB 的长度/实际训练 token 差异仍需增加匹配长度的控制实验。

## H-FedSA 迁移与 2×2 对照

`hfedsa` 是独立固定 beta 实现，不是原始代码直接迁移，也不包括 DDPG。三个特征为方向余弦、更新 L2/Frobenius 范数及维度归一化 L1/L2。特征标准化后使用完整协方差 GMM。按簇中心的原始更新强度排序：最低为异质、中间为普通良性、最高为恶意。权重为样本量乘 `p_benign * max(cos, 0) + beta * p_heterogeneous`，再归一化。所有特征退化或 GMM 不收敛时仅采用服务器参考更新，并将检测率记为未定义，不能记作零误判。

原始表示是客户端相对全局的 A/B 因子差拼接。有效表示是每模块 `c*B_i*A_i - c*B_g*A_g`。2×2 比较原始/有效表示与强度排序/锚点身份匹配，聚合均采用有效更新及相同截断规则。不同表示的方向、范数、L1/L2 定义保持对应。另设 factor-average 对照才能单独讨论因子聚合偏差。

当前低秩范数、内积、聚合不构造整层稠密矩阵；**精确 L1 仍需要按行分块计算矩阵元素**，其时间复杂度不是纯小矩阵级别，必须计入服务器开销。不能宣称所有结构特征均具有低秩复杂度。秩固定的截断 SVD 有损，记录实际尾部能量和相对误差。

## 候选锚点方法

`anchor_gmm` 在每轮全局模型上，利用服务器 root 池生成普通、异质和已知触发攻击三类参考适配器，每类默认 2 个、2 个本地优化步。普通锚点来自 SST-2，异质锚点来自 IMDB，恶意锚点来自有监督生成的后门数据。锚点与客户端一起拟合 GMM，枚举 3! 个簇身份映射，选择锚点平均后验匹配最高者。匹配可靠性阈值可配置，默认 0 只记录、不作可靠性保证。

三类锚点并不意味着当轮真实客户端一定包含三类。没有客户端攻击时，恶意成分可以仅解释人工攻击锚点。这里的 GMM 概率是模型责任分数，尚无校准或误判率保证。锚点步数与真实客户端步数不同可能造成分布差异，需要消融及预算扫描。

`hybrid` 对归一化熵高于阈值的更新及少量随机抽检更新增加行为探测。以每个验证域相对全局的 NLL 变化作为行为特征；将结构及行为特征输入仅用服务器锚点训练的正则化逻辑回归，再更新这些客户端的三类分数。默认 6 个锚点只是工程起点，不能据此假定泛化可靠。

锚点方法使用已知辅助域和已知攻击监督；主对照必须使用 `matched_reference.yaml` 的相同双域参考池。单域 pilot 与双域候选方法之间的差异不能单独归因于算法。当前留出一个不同的测试触发词仅是触发词迁移，不是留出整个攻击家族。真正的未知域、未知攻击家族和自适应规避攻击仍是后续研究任务。

## 其他基线

- `fedavg`：按样本量聚合。默认作用于有效更新，输出固定秩近似；`aggregation.mode=factor` 是单独的传统因子平均基线。
- `fltrust`：用有效更新与可信更新余弦加权，将有效更新范数归一到可信更新，再做固定秩聚合。这是明确的 LoRA 迁移版。
- `rfa`：在有效更新空间使用低秩 Gram 矩阵实现 Weiszfeld 迭代，求加权几何中位数系数，再作固定秩回写。该截断步骤与原始 RFA 的无截断空间不同。
- 这些无显式恶意分类器的方法不虚构检测概率/FPR；统一报告任务性能、ASR 与贡献权重。

FLoRA、FedEx-LoRA、GLoRA、CLAIR、PEFTGuard 尚未在本仓库实现。不能用同名占位实现或这些迁移基线冒充它们。异构秩、DDPG、自然指令任务、理论安全保证也不在首版范围内。

## 攻击与评价

固定恶意身份从普通客户端中按数据种子抽取，每轮仍随机参与，因此实际恶意数量变化。标签翻转修改指定比例训练标签；后门仅从非目标类选取最多 `poison_fraction * N` 条样本，前缀插入触发词并改为目标标签；ASR 分母只包含非目标类测试样本。训练数据原对象不被就地修改。

更新缩放在有效权重空间实施 `global + scale * (local - global)`，再投影回客户端秩，单独记录投影误差。它与同时缩放 A/B 不等价，报告中不得混称。此攻击只报告任务损害，没有触发式 ASR。

客户端真实角色仅在防御返回后附加到日志。验证集用于模型开发/探测；测试集仅在预定最后一轮评价，不进入权重或参数更新。不按测试准确率挑选最佳轮次。软件测试还会翻转全部测试标签，验证训练出的适配器完全不变。

FPR 分别对普通良性和正常异质客户端报告；TPR 对恶意客户端报告。缺失角色或未给出风险分数时为 null。汇总分别报告每种子比例的均值/标准差，以及池化的分子分母；后者不视作独立样本。主评价需同时考虑 ASR、任务域宏平均及每域性能、异质客户端权重、显存、时间和通信字节。降低 FPR 而放过攻击不构成防御改善。

## 可复现与发布

每轮保存适配器和 RNG、源代码摘要、配置摘要、数据摘要，恢复只接受相同版本。每个客户端使用独立重建的 AdamW；每轮客户端采样种子与本地训练种子显式确定。失败时最多重跑未提交的一轮。不同 GPU / CUDA 软件栈仍可能产生数值差异，应以记录的环境为准。

首批先完成离线数学与状态测试，再进行真实模型两轮资源试验；看到损失下降和正常评价后才运行三种子机制实验。当前所有初始配置都是待验证的实验方案，不预设候选方法优于基线。
