# 工作一代码迁移审计

本批方法命名为 **H-FedSA supplied-code LoRA port（hfedsa_ddpg）**。它不是论文公式的精确复现，也不是上一批 `hfedsa` 固定 beta 简化实现。原材料为用户提供的 H-FedSA.zip。

`legacy_hfedsa.py`、`legacy_ddpg.py`、`legacy_tensor_ops.py` 来自该归档的 `src/defenses/hfedsa.py`、`src/defenses/ddpg_beta_agent.py`、`src/federated/tensor_ops.py`。仅修改前者的包导入路径；文件校验记录见 `results/attack-pilot-20261009/source_provenance.json`。

## 保留的原代码行为

- 三个特征为方向距离 `1-cos`、更新范数与根更新范数的对数比、L1/(维数平方根×L2)；每轮标准化。
- 自定义对角协方差三成分 GMM，最多 30 次 EM、方向排序初始化、正则 1e-6。聚类标签按原代码 `current` 规则由中心特征映射，不读取真实客户端身份。该规则与论文中全协方差、强度排序描述有差异。
- 权重使用原代码 `current` 公式：`max(cos, 0.05 if p_heter > p_benign else 0) × max(0, p_benign + beta × p_heter - 0.8 × p_mal)`，归一化后聚合。风险阈值 0.5 仅用于评价，不另加硬删除。保留退化聚类和全零权重时的原代码回退，并逐轮记录。
- DDPG 两层 64 隐藏单元，学习率均 1e-3，gamma=0.95、tau=0.02，经验池 1000、batch=16、探索噪声 0.05，beta 范围 [0,1]。特征状态 24 维，按原运行配置补零到 32 维。

## 明确的适配与修正

1. raw 是相对轮前全局适配器的 A/B 因子差；effective 是实际 `alpha/rank × (B_i A_i - B_g A_g)`。effective 的内积和范数用低秩代数，L1 分块精确求和；不使用错误的 ΔBΔA。
2. 所有方法统一在实际矩阵更新空间聚合，再 SVD 截断到 rank=4。每轮记录截断误差。FLTrust 额外实施根范数归一化；工作一方法不额外归一化或裁剪。比较中 raw/effective 主要改变检测特征；adaptive 条件的攻击也按所针对表示重新构造，故该条件不能解释为完全相同恶意更新的纯评分消融。
3. 原代码把测试损失/准确率反馈给控制器；此处改为验证集双域平均损失和准确率。最终测试仅在第 50 轮执行，不能选最佳轮或调攻击参数。真实恶意身份不进入奖励，安全项仅用预测为恶意者的平均权重。
4. 原代码对空的预测恶意集合求均值会产生 NaN；改为 0。上一轮准确率为 0 时仍按实际值计算。
5. 原代码把同一个状态填入经验元组的前后状态；修正为下一轮特征可用时保存 `(s_t, a_t, r_t, s_{t+1})`。第 17 轮首次梯度更新，第 50 轮累计 34 次；第 50 轮奖励保存在断点中但不以虚构下一状态再更新。明确这是修正后的迁移基线，不能把效果下降归因于这些旧实现错误。
6. 原始 DDPG 网络、优化器、经验池、随机状态和待处理奖励均随检查点保存。离线重放使用评分前控制器快照与随机状态，只表示固定来源历史下的单轮重评分，不代表另一条闭环训练轨迹。

单元测试核对小矩阵上两种表示的特征/权重与原始代码的稠密计算相符，并检查实际 DDPG 学习、逐位一致的断点恢复和测试标签隔离。合成测试只用于软件核验，不作为研究结果。
