# H-FedSA 工作一迁移：raw 无攻击对照

本项已完成 50 轮，训练种子 2026。配置、数据和训练源码沿用[冻结协议](../../../docs/attack-pilot-20261009.md)，没有依据结果改动参数。最终测试仅在第 50 轮完成后进行。

| 指标 | 结果 | 分母或口径 |
|---|---:|---|
| SST-2 干净准确率 | 93.75% | 240/256 测试样本 |
| IMDB 干净准确率 | 92.58% | 237/256 测试样本 |
| 双域宏平均准确率 | 93.16% | 两个域等权平均 |
| 普通良性误报率 | 28.53% | 107/375 客户端轮次 |
| 异质良性误报率 | 24.80% | 31/125 客户端轮次 |
| 全部良性误报率 | 27.60% | 138/500 客户端轮次 |
| 普通良性平均聚合权重 | 0.09946 | 全部普通良性客户端轮次 |
| 异质良性平均聚合权重 | 0.10163 | 全部异质良性客户端轮次 |
| DDPG 梯度更新 | 34 次 | 第 17 至 50 轮 |
| 逐轮耗时之和 | 129.86 分钟 | 不含最终测试、归档及下载 |

误报定义为真实角色为良性、且防御输出的恶意后验 `p_malicious >= 0.5`；这是冻结阈值。误报标签和实际聚合权重分别报告，不能把误报次数直接等同于完全丢弃更新次数。无攻击对照中，预定的恶意候选客户端也按普通良性客户端运行。

本项表明该配置在无攻击条件下仍会将部分良性更新标为恶意；异质良性误报率没有高于普通良性误报率。不能据此宣称异质性必然导致更严重误判，也不能在缺少配套 FedAvg、effective 和攻击结果时判断整体迁移成败。

本项没有恶意阳性，TPR/recall、FNR、ROC-AUC 和后门 ASR 均不适用。仅有一个训练种子且复用已观察过的数据划分；500 个客户端轮次是相关观测，不是 500 次独立实验，不作显著性推断。本项为实际闭环训练，不是离线重放。

完整数值见 [summary.json](summary.json)；逐轮记录见 [rounds.json](rounds.json)。完整归档为 626,567,249 字节，已下载至本地并通过整个 ZIP 的 SHA-256、CRC 和全部 156 个文件哈希校验，包含 50 轮原始更新、检查点、适配器、配置、数据及环境记录。服务器归档记录见 [backup.json](backup.json)，独立的本地核验回执见 [local_backup_verification.json](local_backup_verification.json)；服务器记录中的 `local_copy_verified: false` 表示服务器归档时尚未做本地校验，本地状态以独立回执为准。控制器参数确实发生变化的核验见 [controller_learning_check.json](controller_learning_check.json)；这只证明发生了学习更新，不证明防御有效。
