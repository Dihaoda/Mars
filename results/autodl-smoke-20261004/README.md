# AutoDL 真实模型运行验收：2026-10-04

本次验证了 Qwen2.5-0.5B 联邦 LoRA 在 AutoDL RTX 5090 上的完整运行流程。它是小规模集成检查，不能用于接受或否定论文假设，也不能据此比较防御算法优劣。

| 检查 | 结果 |
| --- | --- |
| 服务器软件测试 | 25 项通过，7.34 秒 |
| 包依赖检查 | `pip check` 通过 |
| CUDA 与模型 | PyTorch 2.8.0+cu128；真实模型前向、反向、适配器恢复通过 |
| 实验规模 | 20 个客户端中每轮抽取 3 个，2 轮，每客户端至多 2 个优化步，种子 2026 |
| 数据 | 真实 SST-2 / IMDB；客户端各 32 条；每域验证集 16 条、测试集 32 条 |
| 方法与攻击 | 固定 beta H-FedSA 独立迁移版，有效更新表示；无恶意客户端 |
| 第 1 / 2 轮时间 | 29.49 / 29.13 秒 |
| 两轮累计时间 | 58.62 秒 |
| 显存峰值 | PyTorch 已分配内存 2.683 GiB，不等于设备总占用或预留显存 |
| 产物 | 检查点、最终 LoRA 适配器、客户端/轮次日志、CSV、诊断图均已生成 |
| 离线重放 | 同一轮更新的原始因子 H-FedSA 评分及 FLTrust 评分成功运行 |

计时包含客户端训练、服务器参考训练、评分聚合和每轮验证，不包含首次安装、模型下载、模型加载、最终测试及导出。不能直接按该小规模耗时推算完整实验矩阵的预算。
